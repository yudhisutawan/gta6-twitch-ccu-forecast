Forecasts Grand Theft Auto VI's launch-day Twitch concurrent viewers hour by hour (hours 2–24, five quantiles each), learned from past big launches' release days shipped inside each case file: a rolling-midnight median launch-day shape, blended with a log-scale regression on the hour-1 print, with an honest spread. See `main.py` for the method and its leave-one-out validation against the house baseline.

## Run it

```sh
MAKEFUN_INPUT_DIR=input MAKEFUN_OUTPUT_DIR=out python3 main.py
```
